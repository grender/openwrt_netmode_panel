# desktop — тестовая VM из строки меню Mac

Electron-приложение для стенда из [docs/vm-utm.md](../docs/vm-utm.md)
([ADR-0047](../docs/adr/0047-desktop-vm-app.md)).

```sh
make desktop            # из корня: npm ci при первом запуске, затем npm run dev
cd desktop && npm test  # vitest
npm run build           # tsc + сборка в out/; npm start — запустить собранное
```

Нужен Node 22 (`.nvmrc`). Приложение ищет репозиторий уровнем выше
`desktop/`; иначе — `NETMODED_REPO=/путь/к/клону`.

## Что умеет

Окно узкое, страница — аккордеон секций в стиле панели: стили не свои, а
`web/panel/src/styles.css` целиком (`@import` в `src/renderer/src/style.css`).

- **Иконка в строке меню**: серая — VM стоит или не создана, жёлтая —
  запускается / грузится / панель не в режиме `nikki`, зелёная — работает,
  красная — ошибка. Кольцо — системный прокси смотрит в VM.
- **Start / Stop.** Start запускает созданную VM (`scripts/vm/start.sh`,
  UTM или QEMU — что есть); если VM нет — `make vm-up`, вывод в логе
  окна. Stop — `scripts/vm/down.sh`.
- **Panel** — есть, только пока панель VM отвечает (VM запущена, токен
  прочитан, `/api/status` отвечает); иначе секции нет вовсе. Открытая,
  панель занимает окно с левого верхнего угла во всю ширину, в одном стиле
  с остальными секциями; её заголовка нет, а строка «Hide panel» сразу под
  ней закрывает её. Остальные секции при этом свёрнуты под панелью, окно
  вытянуто на всю высоту экрана, прокрутка одна — у окна. Закрыли — окно и
  секции как были; VM погасла — панель закрывается сама. В меню иконки —
  «Open panel» / «Hide panel».
- **Proxy settings** — копирование по частям: хост, порт, логин, пароль,
  `host:port`, `http://…`, `socks5://…`, строка `export` для шелла. Значения
  читаются из VM (`scripts/vm/proxy-info.sh`), порт — из
  `scripts/vm/common.sh`. Для Firefox: хост и порт — в поля HTTP-прокси
  (и «использовать для HTTPS»), логин он спросит сам.
- **macOS system proxy** — включить/выключить на выбранной сетевой службе
  и показать, что действует сейчас (`scutil --proxy`): через VM, другой
  прокси или выключен. Ставятся только хост и порт — логин nikki
  приложения спросят сами (почему — ADR-0047).
- **Автовыключение системного прокси** — перед Stop, при выходе, когда VM
  погасла сама, и при следующем запуске после падения приложения.

Порт и логин прокси одинаковы в режимах `nikki` и `b4` (ADR-0048). В `nikki`
это HTTP и SOCKS5, в `b4` — только SOCKS5 (сервер b4): приложение убирает
HTTP-адрес из списка копирования, строку `export` переводит на `socks5h://`,
а системный прокси при смене режима само переключает на «только SOCKS» и
обратно. В режиме `off` прокси нет вовсе.
