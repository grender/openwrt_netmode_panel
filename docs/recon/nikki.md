# Nikki (mihomo): Clash API

Снято с живого роутера 2026-08-02. mihomo **v1.19.27**, `meta: true`.

## Доступ

| | |
|---|---|
| Адрес | `nikki.mixin.api_listen`, по умолчанию `[::]:9090` |
| Секрет | `nikki.mixin.api_secret` |
| Аутентификация | **`Authorization: Bearer <секрет>`** |

Секрет читается из UCI при старте, копия не хранится — иначе ротация
ломала бы демона (ADR-0002).

**`?secret=` в строке запроса не работает** — проверено, отвечает
`{"message":"Unauthorized"}`. Параметр в ссылке LuCI предназначен самой
веб-морде, которая уже кладёт его в заголовок.

Генерируется при установке шестью десятичными цифрами
(`nikki/files/uci-defaults/init.sh:9`), тем же значением ставится пароль
веб-панели. Мы его только читаем — менять генерацию владелец не просил.

## `GET /proxies`

Корень — **объект, а не массив**: `{"proxies": {"<имя>": {...}}}`. Ключ
совпадает с полем `name`.

Узел: `{alive, name, type, history[], extra{}, id, provider-name, udp, …}`.
Группа: то же плюс `all[]` (участники), `now` (текущий выбор), `type`.

### `delay: 0` означает «пробы не было», а не «ноль миллисекунд»

```json
"history": [ {"time":"…17:14:47Z","delay":0}, {"time":"…17:15:45Z","delay":34} ]
```

Это самая опасная деталь ответа. Нулевую задержку легко принять за
идеальную и покрасить зелёным — то есть показать мёртвый узел как лучший.
Наружу такая запись обязана уходить как `null`, а не как `0`.

`alive` при этом остаётся `true`: он говорит о последней успешной пробе,
а не о последней.

## Раскладка групп на этом роутере

`raw/61-clash-groups.json`:

| Группа | Тип | Сейчас | Участники |
|---|---|---|---|
| `PROXY` | **URLTest** | 🇨🇭⚡Швейцария 2 | 29 узлов провайдера `sub` |
| `BYPASS` | Fallback | PROXY | `[PROXY, REJECT]` |
| `GLOBAL` | Selector | DIRECT | `[DIRECT, REJECT, PROXY, BYPASS]` |

### Расхождение со SPEC §7 — и почему оно не мешает

Спека предполагала, что для ручного выбора `PROXY` обязана быть
**`selector`** со вложенным пунктом `AUTO` (`url-test`). Фактически она —
`URLTest`, и такой группы `AUTO` нет.

**Это не мешает: переделывать профиль не нужно.** Разбор исходников mihomo
показал, что предположение спеки устарело.

`PUT /proxies/{имя}` приводит цель не к конкретному типу, а к интерфейсу
**`SelectAble`** (`hub/route/proxies.go`):

```go
selector, ok := proxy.Adapter().(outboundgroup.SelectAble)
if !ok {
    render.JSON(w, r, newError("Must be a Selector"))   // 400
}
selector.Set(req.Name)
```

`URLTest` его реализует (`adapter/outboundgroup/urltest.go`):

```go
func (u *URLTest) Set(name string) error {
    // проверяет, что участник существует
    u.ForceSet(name)
}
```

Закреплённый узел хранится в поле `selected` и **обходит автоподбор**
в `fast()`, пока непуст. Наружу он отдаётся как **`fixed`** — то самое
поле, которое видно в ответе живого роутера.

### `AUTO` встроен в движок

`DELETE /proxies/{имя}` вызывает `ForceSet("")`, то есть снимает
закрепление и возвращает группу к автовыбору. Работает **только для
не-`Selector`** групп — ровно для `URLTest` и `Fallback`.

Значит внешний контракт спеки сохраняется целиком:
`POST /api/nikki/proxy {"name":"AUTO"}` возвращает к автовыбору — просто
реализуется через `DELETE`, а не через вложенную группу в профиле.

| Поле | Что означает |
|---|---|
| `now` | через какой участник группа работает **сейчас** |
| `fixed` | что закреплено **вручную**; пусто — автовыбор |

Одного `now` недостаточно: по нему «закреплено руками» и «движок так
решил» неразличимы, а для панели разница принципиальна.

### Остаточный риск закрепления

Тревога спеки про fail-closed остаётся в силе, хоть и по другой причине.
`BYPASS` — `Fallback[PROXY, REJECT]`: когда `PROXY` умирает целиком,
трафик уходит в `REJECT`, а не напрямую.

Пока выбор автоматический, признак «жива» честен. Что происходит, когда
закреплён **мёртвый** узел, по исходникам не прослежено — не проверяли.
Поэтому закрепление трактуется как **временное действие**: панель держит
возврат к `AUTO` на виду, а не прячет в меню.

## Замер задержек

`GET /proxies/{имя}/delay?timeout=<мс>&url=<проба>`

URL пробы, которым пользуется сам движок, виден в ответе `/proxies` —
`extra` ключуется им: `https://www.gstatic.com/generate_204`.

Форма ответа снята на живом роутере (RQ-06, 2026-08-07):

```
curl -s -H "Authorization: Bearer $S" \
  "http://127.0.0.1:9090/proxies/PROXY/delay?timeout=3000&url=https://www.gstatic.com/generate_204"
{"delay":25}
```

Поле ровно одно. Несуществующее имя отвергается — `{"message":"Resource not
found"}` с кодом не 200, так что успеху можно верить и отдельно проверять
существование узла не нужно.

Замер — **триггер**, а не источник чисел: задержки приходят в `/proxies` и
без него, mihomo обновляет `history` сам примерно раз в пять минут (видно по
меткам времени в `raw/60-clash-proxies.json`). Отсюда и форма ответа
`POST /api/nikki/test`: список плюс поле `test` с итогом — по одним числам
отличить состоявшийся замер от несостоявшегося нельзя.

Для группы путь отдаёт задержку **выбранного члена**, а не всех: чтобы
обновить всех, надо звать по каждому имени из `all[]`. Отдельный групповой
эндпоинт `/group/{имя}/delay` не снимался и в коде не используется.

## Прочее

Два узла в списке — сырые `адрес:порт`, остальные с именами из `remarks`.
Запись `⬇️ Обходы белых списков ⬇️` — разделитель провайдера, а не узел;
подключиться к нему нельзя.

**Прежнее решение — «показывать как есть, разделители не угадывать» — снято.**
Оно опиралось на опасение спрятать настоящий узел с похожим именем. Разведка
подписки 2026-09-03 ([`happ.md`](happ.md)) показала, что эта запись —
побайтовая копия узла `🇩🇪⚪Германия (БС-3)☁️` и структурно от узла
неотличима: единственный признак — имя, которое у всех остальных записей
начинается с эмодзи-флага. Признак опознаётся конвертером подписки, разделитель
приходит в панель как заголовок, а не как кнопка. Эвристичность признака и её
цена приняты в ADR-0031.
