# Журнал архитектурных решений

Последствия / Рассмотренные альтернативы**. Решения приняты после разведки
(`docs/recon/`), поэтому ссылаются на реальные ответы роутера, а не на
предположения.

побеждает ADR.** Спека осталась базой, но часть её решений отменена
владельцем осознанно; см. [ADR-0018](0018-spec-superseded.md).
